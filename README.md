# Timothy Ndichu — Portfolio

Personal portfolio for software engineering work, projects, and technical writing.

## Stack
- React 18
- TypeScript
- Tailwind CSS 3
- Create React App with CRACO for Tailwind integration

## Local development
```bash
npm install
npm start
```

Create a production build with `npm run build`.

## Canonical URL
The portfolio is hosted at https://timndichu-portfolio.vercel.app/. The GitHub Pages domain https://timndichu.github.io redirects visitors to the canonical site.
